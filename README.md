# ControlPagos 💰

Aplicación simple para gestión de finanzas personales (Cuentas por cobrar, por pagar, clases y ahorros).

## 🚀 Cómo iniciar

1.  **Instalar dependencias** (solo la primera vez):

    ```bash
    npm install
    ```

2.  **Ejecutar**:

    - Dale doble clic al archivo `iniciar.bat`.
    - O ejecuta en la terminal: `npm start`

3.  **Usar**:
    - Se abrirá automáticamente en tu navegador.
    - Tus datos se guardan en `db.json`.

## 📁 Archivos importantes

- `db.json`: Tu base de datos (No compartir).
- `iniciar.bat`: Acceso directo para abrir la app.
